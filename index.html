03 / Typography

Typography & brand language

Matter gives EFC a clear, consistent voice across design and communication.

Our tagline

From Lead
to Black Belt

Brand name

EFC · EFC Software · EFC CRM

Use EFC as the brand name. Use EFC Software or EFC CRM when referring to the relevant product. Do not expand the initials.

Brand voice

Clear, practical and grounded in the experience of martial arts school owners. Use specific examples, sentence case and straightforward language.

Use the tagline where it supports the message. It does not need to accompany every use of the logo.

Primary typeface

Matter
RegularMediumSemiBold
Download Matter ↗Download DM Sans

Install before you start

Install Matter on your computer before editing EFC materials in desktop apps. This preserves the intended letterforms, spacing and line breaks.

Regular for body text. Medium for emphasis. SemiBold for headings.

When Matter is unavailable, use DM Sans consistently throughout the document. Use Arial only if neither font is supported.

Choose the right font for your application
Application Typeface Guidance
PowerPoint, Word & desktop design apps Matter Download and install Regular, Medium and SemiBold, then reopen your app. If you switch to DM Sans, check the text wrapping before export.
Google Slides DM Sans The EFC templates use DM Sans for consistent sharing. Installing Matter locally does not add it to Google Slides.
Canva Matter or DM Sans Use Matter if it is available in your Brand Kit. Otherwise use DM Sans. A local font installation does not upload the font to Canva.
Other applications DM Sans or Arial Use one fallback consistently and check line breaks, spacing and alignment before publishing.
Install Matter on your computer

Mac

  1. Download the Matter font files using the link above. Unzip them if needed.
  2. Double-click each .otf or .ttf file and choose Install in Font Book.
  3. Install Regular, Medium and SemiBold, then reopen your app.

Apple installation guide

Windows

  1. Download the Matter font files using the link above. Unzip them if needed.
  2. Right-click each .otf or .ttf file and choose Install.
  3. Install Regular, Medium and SemiBold, then reopen your app.

Microsoft installation guide

Set up fonts in Google Slides or Canva

Google Slides

Open the font menu, select More fonts, search for DM Sans and select OK. Apply the same font throughout your presentation.

The presentation templates below already use DM Sans.

Canva

On a supported Canva plan, a team owner, admin or brand designer can upload Matter to your Brand Kit. Installing it on your computer does not add it to Canva. Use DM Sans if font upload is unavailable.
